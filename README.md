### Clover Cycle Android App ###
Play Store Listing TBD (how have I never set up a personal developer account?)

Fetches Portland cycling events from `https://www.shift2bikes.org/api/` and lets you view, sort, and store them.

(api specs at https://github.com/shift-org/shift-docs/blob/main/docs/CALENDAR_API.md)

**Current Features**
* get events by date or range
* expand events for more information
* save events with long press
* saved events are highlighted and persisted

**Future Features**
* map integration
  * sort by distance
  * map & pin view for fetched & saved events
  * route planning
* search api integration (see api specs)
* create calendar events
* update events with "newsflash" (see api)
